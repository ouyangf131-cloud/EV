# 05 澳大利亚汽车维修工作：「如何核实」框架（Australia Notes）

> 【示例教学材料，非某车厂正式手册】教学示例，使用前以现行车厂手册与法规为准。
> ⚠️ **本文不包含任何具体的分数线、工作年限、费用、职业代码或执照条件。** 这些信息经常变化，必须去官方机构网站查当前版本，并记录**来源网址和查询日期**。本文不构成移民、法律或职业建议。

## 1. 使用规则（助手和 Mike 都要遵守）

1. 任何关于澳洲工作、签证、技能评估、执照、英语要求的说法，都要附上：**机构名称 + 网址 + 查询日期**
2. 查不到或不确定 → 写「不知道 / 待核实」，不要用记忆或网上传言填空
3. 非官方来源（中介、论坛、视频、AI 回答，包括本助手）只能作为线索，必须回到官方来源核对
4. 规定按**州/领地**可能不同，记录时写清楚适用的州/领地

## 2. 需要核实的问题清单

| 问题 | 去哪类官方渠道查 |
|------|------------------|
| 我的职业（如汽车机修工 / 汽车电工）在哪个职业清单上？对应的职业名称和代码是什么？ | 澳大利亚 Department of Home Affairs（移民与签证官方网站）上的职业清单页面 |
| 这个职业由哪个机构做技能评估（skills assessment）？ | Home Affairs 职业清单中列出的评估机构（assessing authority）；汽车类技工职业常见的评估机构之一是 Trades Recognition Australia (TRA)——**以职业清单实际列出的为准** |
| 技能评估需要什么材料、经验、是否要实操考核？ | 对应评估机构官网（如 TRA 官网）及其指定的评估服务提供方 |
| 签证的英语要求是什么？接受哪些考试？分数多少？ | Department of Home Affairs 官网对应签证页面（**助手不提供分数，必须自己查当天版本**） |
| 澳洲的汽车维修相关正规资格和 EV / 高压相关能力单元有哪些？ | training.gov.au（全国职业教育与培训登记官方网站），搜索 automotive、electric vehicle、high voltage |
| 在某个州工作需要哪种执照或注册？ | 该州/领地负责汽车维修行业执照的主管部门，以及州/领地的培训主管部门（state training authority） |
| 雇主通常要求什么？ | 招聘广告和雇主本身；行业协会（非政府机构，信息需与官方来源交叉核实） |
| 汽车维修信息怎么获取（独立维修者能否拿到车厂资料）？ | 澳大利亚政府关于汽车维修信息共享制度的官方页面：ACCC 的 Motor Vehicle Information Scheme 说明页（网址见 2.1；适用范围和获取方式以页面当天内容为准） |

## 4. 品牌经验的整理建议（为以后简历/评估准备）

如果你修过 Tesla、GAC Aion、BYD、Toyota、Nissan、Honda、VW ID.、BMW i、Mercedes EQ 等品牌车辆，可以平时就整理：
- 车型、年份、做过的工作内容（用英文写，术语参考 04-glossary-en）
- 参加过的培训、证书原件和英文翻译件
- 工作证明（雇主、时间、岗位）
是否需要、需要什么格式，**以评估机构官方要求为准**。

## 5. 不要相信的说法（示例）

- "雅思随便几分就够" / "肯定要 X 分" —— 没有官方来源和日期的都不要信
- "有 XX 证就能直接在澳洲修电动车" —— 需要查州/领地规定和雇主要求
- "这个职业一定在清单上" —— 清单会调整，查当前版本
