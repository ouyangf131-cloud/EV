# 03 高压安全原则（High-Voltage Safety Principles）

> 【示例教学材料，非某车厂正式手册】教学示例，使用前以现行车厂手册与法规为准。
> **本文刻意不包含任何高压作业操作步骤。** 高压作业步骤因品牌车型而异，只能来自该品牌的官方维修手册，并由受过培训、有资质的人员执行。

## 1. 为什么高压危险

- **触电（Electric shock）**：电动车和混动车的动力电池电压远高于 12V 低压系统，足以造成严重伤害甚至死亡。
- **电弧（Arc flash）**：高压回路在带电状态下断开或短路，可能产生电弧，造成烧伤。
- **电池热失控（Thermal runaway）**：电池受损、进水或过热后可能起火，且难以扑灭。
- **残余电能**：车辆熄火、仪表不亮、"没电了"都**不等于**高压系统已经安全。电容等部件可能仍有储能。

## 2. 谁可以做高压作业

- 经过**正规 EV / 高压安全培训**并取得相应资质的人员
- 熟悉**该品牌该车型官方维修手册**的人员
- 遵守**所在国家/地区法规**和**雇主安全规程**的人员
- 在澳大利亚：相关培训课程和能力单元可在 training.gov.au 查询（搜索 electric vehicle、high voltage 等关键词），具体要求以州/领地主管部门和雇主为准（**待核实，请记录来源与日期**）

## 3. 基本安全原则（概念层面，不是步骤）

| 原则 | 说明 |
|------|------|
| 先查手册 | 每次作业前查阅该车型现行官方维修手册和技术通报（TSB） |
| 识别高压部件 | 高压线束通常为**橙色**；高压部件上一般有警告标识 |
| PPE 个人防护装备 | 按手册和规程使用合格的绝缘手套、护目/面罩等；PPE 需定期检查，等级要匹配作业要求（**具体等级以官方要求为准，本文不给数值**） |
| 绝缘工具 | 使用合格的绝缘工具和符合要求的测量仪表 |
| 隔离与标识 | 工作区域隔离，车辆挂警示标识，防止他人误操作（相关做法称为 lockout/tagout，具体按规程） |
| 两人原则 | 很多安全规程要求高压作业时有第二人在场并懂得应急处置（以所在单位规程为准） |
| 验证安全状态 | 必须按官方手册规定的方法确认高压系统处于安全状态后才能作业 |
| 不绕过安全系统 | 绝不短接高压互锁（HVIL）、屏蔽绝缘报警或绕过任何安全装置 |

## 4. 学习者（新手）可以安全做的事

- 学习系统原理、部件作用、英文术语
- 练习阅读官方维修手册的结构和安全章节
- 跟随有资质的技师观摩学习
- 低压（12V）系统的基础学习，仍需遵守车间安全规定
- 整理"向师傅/售后提问"的问题清单

## 5. 紧急情况

车辆冒烟、起火、泡水、碰撞后电池区域受损：
1. 人员远离车辆
2. 联系紧急服务和品牌售后/道路救援，并告知这是电动车或混动车
3. 不要尝试自行处理高压部件
