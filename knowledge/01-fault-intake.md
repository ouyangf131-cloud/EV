# 01 故障问诊清单（Fault Intake Checklist）

> 【示例教学材料，非某车厂正式手册】教学示例，使用前以现行车厂手册与法规为准。

## 1. 为什么要先问诊

同一个症状（例如"上不了电""不能充电"）在不同品牌、车型、年款、动力类型上可能有很多原因。先把信息问清楚，才能给出有依据的排查方向，避免乱猜和误修。

## 2. 必问信息

| 项目 | 为什么要问 | 回答示例 |
|------|-----------|----------|
| 品牌 Brand | 不同品牌的系统设计、诊断工具、官方资料渠道不同 | Tesla、GAC Aion 广汽埃安、BYD 比亚迪、Toyota 丰田、Nissan 日产、Honda 本田、Volkswagen 大众（ID. 系列）、BMW 宝马（i 系列）、Mercedes-Benz 奔驰（EQ 系列） |
| 车型 Model | 同品牌不同车型差异很大 | Model 3、AION S、海豚 Dolphin、bZ4X、Leaf、ID.4、iX3、EQA |
| 能否上电 / 进入 READY | 区分"低压/上电问题"和"上电后的问题" | 能 READY / 不能 READY / 屏幕都不亮 / 不确定 |
| 症状 Symptom | 用户原话最重要 | 加速无力、不能充电、异响、续航突然变短 |

## 3. 建议问的信息

| 项目 | 说明 |
|------|------|
| 年款 Model year | 同车型不同年款的软件和硬件可能不同 |
| 动力类型 Powertrain | BEV 纯电 / PHEV 插电混动 / HEV 油电混动（例如 Toyota 的很多混动车型属于 HEV，BYD DM-i 车型属于 PHEV，具体以车型资料为准） |
| 里程 Mileage | 判断零部件老化可能性 |
| 仪表提示 Dashboard warning | 请用户记录**原文**或描述图案和颜色；不要凭图案猜含义，以车辆用户手册为准 |
| 诊断仪读数 Scan tool data | 如已读取故障码（DTC），请原样记录字符串、冻结帧（freeze frame）信息；**含义必须对照该品牌官方资料** |
| 最近事件 Recent events | 涉水、碰撞、维修、改装、长期停放、软件更新、充电时出现、极端天气 |
| 出现频率 | 一直存在 / 偶尔出现（间歇性故障 intermittent fault）/ 特定条件下出现 |

## 4. 安全红线（先问这些）

出现以下任一情况，**先停止使用车辆，远离车辆，联系品牌售后或道路救援**，不要自行检查高压部件：
- 冒烟、焦糊味、明火
- 车辆泡水或深度涉水
- 碰撞后底盘/电池区域受损
- 高压线束（通常为橙色）破损、外露
- 仪表提示绝缘故障或高压系统严重故障，同时伴随异味或异响

## 5. 各品牌官方信息去哪找（一般性指引，待核实）

- 品牌授权服务中心（任何品牌都适用，最可靠的起点）
- 品牌官方售后/技术信息网站：部分车厂向独立维修者提供付费或免费的维修信息访问（例如 Tesla 有在线服务信息网站（访问方式与地区可用性待核实）；其他品牌的名称、获取方式和地区可用性**待核实**）
- 原厂诊断软件/设备，或支持该品牌的专业诊断仪
- 在澳大利亚：有汽车维修信息共享相关的制度安排（具体名称、适用范围和访问方式**待核实**，请查澳大利亚政府官方信息）
- 召回信息：查所在国家/地区的官方召回数据库
